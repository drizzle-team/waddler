## Breaking changes

### Standalone `sql`

The `sql` utility is now imported directly from dialect-specific core packages:

```ts
import { sql } from "waddler/<dialect>-core";
```

Example:

```ts
import { sql } from "waddler/pg-core";

// You can then reuse this query in other sql statements
const sqlQuery = sql`select ${sql.identifier("id")} from ${sql.identifier(
  "users"
)}`;

console.log(sqlQuery.toSQL());
```

Previously, `sql` had to be imported from the driver-specific package:

```ts
import { sql } from "waddler/node-postgres";

// You can then reuse this query in other sql statements
const sqlQuery = sql`select ${sql.identifier("id")} from ${sql.identifier(
  "users"
)}`;

console.log(sqlQuery.toSQL());
```

**Reason for upgrade**

Standalone `sql` depends only on the dialect you are using. Importing it from a driver-specific package tied it unnecessarily to a specific implementation, which was considered a bad practice.

## Features

### New dialects

- Added support for the `CockroachDB` database with the dialect-specific package `waddler/cockroach-core`;
- Added support for the `MSSQL` database with the dialect-specific package `waddler/mssql-core`.

### New driver

- Added support for `node-mssql` with the driver-specific package `waddler/node-mssql`.
